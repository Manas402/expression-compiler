# Tests

Place automated tests and/or organized test cases in this directory. Suggested groupings:

- `test_lexer.py`: token recognition and invalid characters
- `test_parser.py`: final CFG, operator precedence, AST shape, syntax errors
- `test_semantic.py`: identifier declaration and operand-type rules implemented by the team
- Integration tests for the Flask route and displayed results

These are suggested filenames, not completed test files. Match the tests to the actual module APIs and language specification.
